# KIOSK Platform

A clean, modular business operating platform built from a new foundation.

## Product direction

KIOSK is an all-in-one platform where businesses manage customers, sales, inventory, conversations, finances, and operations — all in one place.

Tagline: **Your business, under one roof.**
